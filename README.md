完全使用 **Go + mygo `ui`** 的原生桌面刷题应用。窗口、导航、题目、选项、笔记与草稿均由原生组件和 Painter 绘制，运行时不加载 WebView、HTML、React 或 JavaScript，也不启动 HTTP 服务。

## 构建与检查

需要 Go 1.27.3+。普通构建只使用 Go，无需 npm/Vite。

```sh

go test ./...
# 从源码运行（同样检查数位笔补丁）
```

应用入口 `main.go`；原生界面、模型、复习算法与富文本适配在 `internal/nativeapp/`；原子存储在 `internal/store/`。`prototype/` 保留原题数据、字体、图片和旧版 Web 原型归档，当前桌面入口不会加载旧前端。独立笔迹引擎演示仍在 `cmd/ink-demo/`，刷题草稿纸通过 `internal/inkcanvas` 使用同一原生笔迹引擎。

## 界面与流程

三个做题页统一使用原生 240px 侧栏、中央题目卡片和 300px 进度/答题卡栏。章节、随机配置和笔记页面也按用户提供的设计稿实现。设计稿只提供外观参考，所有界面均由 Go + MyGo `ui` 绘制。保留明暗主题和嵌入字体。

- 章节练习：学科导航、章节与记录筛选、题目目录、题干/slug/页码搜索。
- 错题复习：右侧切换今日到期/全部错题，点击答题卡跳题，重新随机会先筛选到期题。本轮卡号和位置在作答及重启后保持稳定。答对不会自动移出错题本。单空题支持 1–4 选择、Enter 提交；题目右键菜单保留独立/不确定/不会操作。
- 随机练习：按学科、范围和题量无放回抽取，保存本轮顺序和位置。
- 作答：支持单选和多空，独立/不确定/不会分开记录；核对原表答案后显示原解析，支持撤销本次作答与安排。
- 草稿：点击题目右侧“草稿纸”进入原生无限画布，题目锚定在画布起点，与笔迹一起平移、缩放；“回到题目”恢复初始位置和 80% 缩放，百分比按钮可恢复 100%。缩放限制为 50%–200%，加减按钮每次变化 10%；滚轮与捏合使用缓和的倍率增长，单次事件最大变化 12%。支持钢笔/圆珠笔、铅笔、荧光笔、整笔/区域橡皮、套索移动、复制/粘贴/删除、撤销/重做、平移缩放。画布暗色底配白色默认墨迹，浅色底配黑色默认墨迹；已写的默认墨迹随主题切换。
- 面板：点左上题号展开进度；点右上“本题笔记”按钮打开或收起笔记卡。套索选中笔迹后点“存入本题笔记”，保存为可随主题显示的矢量片段。笔记和片段在最后一次编辑后短暂防抖自动保存（连续输入最长 3 秒落盘一次），跳题、退出画布和关闭窗口时立即写入；同步开关可单独隐藏列表条目。
- 画布性能：小地图已移除，不再生成总览图或安排它的重绘计时器。当前笔画复用固定大小的绘制缓冲，避免每次起笔重新分配全屏纹理；干笔与平移备用缓冲按需分配，平移预留边界从 192 缩到 96 个物理像素。退出画布时释放绘制缓存，会话笔迹仍保留。缩放时先用上一张已烘焙视图做临时预览；缩小时旧图未覆盖的新视野只补画纸面；小文档再补画该区域矢量笔迹。大量笔迹时新露出区域保留纸面，等停手后的分帧重建补齐，避免每帧重画全部笔迹；旧视野内的笔迹不会再被整屏纸色覆盖。停手 180ms 后再按新倍率重建矢量底图；这样不会每个捏合帧都重画全部笔迹。画布打开时不安排周期保活帧；若出现超过 1.8 秒的帧间隔，会先检查后台保留的完整视野纹理；有效则复用，失效才从矢量笔迹完整恢复，避免把空纹理显示出来。橡皮擦的圆环由画布自绘，系统指针同时隐藏。
- 备份：原生文件对话框导入/导出兼容旧版 JSON。导入先验证，再确认覆盖；自动保存导入前的文件备份。

## 公式显示

MyGo 原生 Markdown 负责文字和段落布局。1,675 种原题公式在构建资产时生成 SVG 路径，行内公式通过原生 InlineObject 嵌入，显示公式通过原生 SVG 显示。公式中的 262 个文本对象已转换为用户字体轮廓，没有残留 SVG text 或缺字。生成报告在 `native-assets/math/report.json`。

这些资产已经包含在仓库中。日常构建和应用运行均不需要 MathJax、Python 或 JavaScript。需要重新生成题库公式时，使用 `scripts/prepare-native-math.cjs`（MathJax 3.2.2）和 `scripts/native-math-outlines.py`（fontTools）。MathJax 许可保存在 `native-assets/MATHJAX-LICENSE.txt`。

### 原生画布存储
草稿纸仅保留在本次应用会话的内存中：切题、关闭再打开画布会保留该题的笔迹和视角，完全退出应用后清空，重新启动不恢复。旧学习文件中的 `ink` / `strokes` 仍原样保留，但不会加载到草稿或再被草稿更新；主动“存入本题笔记”的矢量片段使用 `inkClips` 持久保存。读取不支持版本/无效数值时仍停止并保留原文件。独立演示仍可 `go run ./cmd/ink-demo` 启动。

笔记片段预览使用独立的只读渲染器，不会替换草稿编辑器；从笔记页首次打开草稿仍按 80% 初始缩放。套索选中后，可用浮动按钮或右键菜单复制、粘贴、删除；快捷键为 ⌘C、⌘V、Delete / Backspace，⌘Z 撤销、⌘⇧Z 重做。粘贴保留笔迹压力及擦除遮罩并选中新副本，重复粘贴会错开位置；移到其他画布位置或切题后也可粘贴。
- 画布题目清晰度：题目卡按相机缩放直接排版（宽度、间距、字号、选项高度同步乘以缩放倍率），不再对 100% 卡片做位图式缩放；放大后文字与行内公式保持矢量清晰，原题图片只加载一份稳定位图，按画布倍率显示尺寸；缩放时不重新加载，不会闪烁，但仍受原图像素限制。
- 选项排除：在答题界面长按任一选项约 0.45 秒可“划掉”该选项，文字、字母块、边框和背景变浅并加删除线；只有再次长按可取消删除线，短按不做任何操作；恢复后短按才可选中，数字快捷键跳过已排除选项。删除线只在本次进入该题期间有效；每次重新打开题目（包括切题后返回、重启应用）自动清除，打开草稿或笔记不清除。

画布稳定性更新：缓存恢复以实际绘制间隔为准，并在窗口重新激活时检查保留图层的有效性，必要时重建；画布不会在重建时自动抢焦点。数位笔输入被系统取消时，保留已收到的笔迹片段，不跨中断补直线。自动保存仍按原有节奏进行，完整编码与落盘改在后台，切题和关闭时等待最新保存完成。

数位板采样修复：项目内 `vendor` 固定 MyGo v0.8.3，数位笔独立事件使用 `locationInWindow` 的事件坐标，不再读取处理时的全局光标位置。画布打开期间暂时关闭本进程 AppKit 的鼠标/数位笔事件合并，关闭画布时恢复之前的设置；不会更改系统设置或其他应用。构建/启动脚本会检查并应用该补丁。若重新执行 `go mod vendor`，先运行 `go run ./scripts/mygo-tablet-patch`；升级 MyGo 时须重新审查补丁。真实数位板与驱动的效果仍需实测。

解析展开或题卡高度发生变化时，会请求分帧重建完整笔迹底图：保留上一张完整视野，每帧最多处理 8 条可见笔迹，不再在提交答案的那一帧同步清空并重建全部笔迹。缩放预览只按最后一次缩放输入计时，普通重绘不会延长等待；停手约 180ms 后重建清晰矢量底图。

笔记支持原生 Markdown 预览：题目侧栏和画布笔记卡可切换“预览 / 编辑”，“我的笔记”在阅读时渲染 Markdown。编辑时按 ⌘V 或使用原生粘贴菜单可插入剪贴板图片（包含 macOS 截图 / TIFF 自动转 PNG）。图片插入当前光标或替换选区，按内容去重，使用简短 Markdown 引用；图片数据保存在对应学习记录的 `noteImages` 附件中，重启和 JSON 备份导入导出均保留。单张图片最多 8 MB、2000 万像素，超出时会提示先裁剪。

导航性能：平移时立即修复当前帧新进入视野的区域，不再等待停手；通过笔迹空间索引跳过无关区域，并复用小笔画的完整遮罩（像素缓存最多 4 MiB、绘制指令最多 8192 段），退出画布时释放；大幅缩放停手后将清晰底图分帧重建（每帧至多处理 8 条可见笔迹），完成前保留原图预览，新输入会取代未完成的重建。重绘会提前剔除修复区域外的线段。准备好的矢量几何限制在 256 条 / 16,384 段以内，退出画布时释放；不按历史视野无限积累大图。

连续平移不会等待缩放重建任务完成，也不会反复取消重建而长期显示缺笔迹的旧预览。缩放分帧重建期间若开始平移，会先建立一张完整的当前视野，再继续边缘增量绘制。

项目性能检查记录见 `native-review/PERFORMANCE.md`。当前答题卡使用原生虚拟列表，普通页面帧不再构建全部题号；富文本缓存有容量上限；长笔画几何准备复用一个预分配数组，原始笔迹与复习规则保持不变。

草稿状态优化：普通抬笔、撤销和重做只更新当前编辑器；切题、退出画布或显式保存时才捕获会话快照。撤销仍保留最多 50 步，但历史只存新增/删除/修改的笔画，未改动的笔画列表不再整表复制。macOS 空闲回收只请求保留最后一个完整视野的纹理，后备保留预算最多 128 MiB（通常只用一张视野纹理），备用缓存仍释放；关闭画布后取消保留。没有保活帧，真正纹理丢失时仍按原矢量数据恢复。原始草稿仍不跨应用退出保存。

数位笔输入隔离：画布在笔接触期间会拦截混入的鼠标/其他指针事件，避免其改变笔迹坐标或抢走当前捕获；真实系统取消仍会结束笔画并保留已收到的片段。画布设置新增“复制画布诊断”，可手动复制采样投递间隔、捕获取消、重复按下及拦截事件的统计和最近 32 条异常时间，不包含题目、坐标或笔迹，也不会自动写日志。统计中的间隔不等于硬件漏采样，真实数位板与驱动仍需体验确认。

区域缓存：平移新露出的区域和局部擦除/移动修复，使用 256 物理像素分块（附 2px 防接缝边缘），按最近使用淘汰。缓存表像素预算为 32 MiB，最多 124 块；这不是应用总 GPU/RSS 上限。编辑只使受影响块失效，删除早期笔画不会连带清空后续无关块；切换倍率、像素密度或主题时换用对应的新分块集合。新视野当帧补齐，已淘汰区域按原始笔迹重建。索套拖动改为按 z-order 分段：选区前静态底图 + 选中/未选中连续段图层/直接绘制 + 选区后段；全选时直接复用当前完整底图作为移动图层。拖动期间按原绘制顺序合成，松手才提交。段数或像素超过预算时回退为精确的选区范围直接绘制。删除和局部修补继续只处理受影响图块内的脏子矩形。原有缩放分帧重建和空闲恢复保护继续保留，首次访问新区域仍有绘制开销。

真实 Metal 分块对照检查：`./scripts/test-canvas-metal.sh`。它通过临时 Go overlay 启用测试后端，退出后自动清理，不改变正式应用或学习数据。更多基准和验证范围见 `native-review/PERFORMANCE.md`。


复习排期（2026-11-11）：独立答对依次安排约 3、7、14、30 天，之后为 60、120、240、365 天；不确定或看过提示的答对约 1 天后再测；答错、不会约 10 分钟后短期重学。使用完整真实天数，提前练习不推进周期；旧排期在下一次有效作答前保持原样。HLR 仍更新真实间隔下的记忆估计，错题本成员资格、原始作答历史及争议答案保护保持不变。

缩放稳定性（2026-11-12）：反向缩放回完整缓存视野时，会立即取消旧重建任务。补边预览与清晰重建同时按笔画复杂度限流，避免少量长笔画绕过数量限制、集中拖慢一帧；保留原始采样与压感，重建完成后整体替换底图，不把半透明笔画分段叠色。

题干序号排版：章节练习、随机练习、错题复习及草稿画布统一把连续罗马数字/圈号条目分段显示，每个序号独立起行，长条目自然换行。只调整显示，不修改原题数据、选项组合、公式或笔记。当前原题库共匹配 185 道题。

数位笔与触控板分离：正式应用采用“纸面 → 原生题目 → 透明笔迹”的层次，数位笔可直接在题干、选项和解析上标注，笔迹跟随同一世界坐标缩放/平移。触控板/鼠标穿透笔迹层，可选择复制文字、右键复制完整题干或 Markdown、点击选项和长按排除；空白纸面的主键拖动用于平移。浮动工具与笔记面板仍可操作。橡皮只擦笔迹，露出下方题目。按笔期间保持数位笔捕获隔离；抬笔后可继续触控板交互。草稿会话寿命与学习数据格式保持原样，独立 ink-demo 不改变原有行为。
