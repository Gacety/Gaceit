# 错题复习算法

当前实现为 **HLR 本地适配版（hlr-local-v1）**。它用每题的真实作答和时间间隔，更新半衰期估计；排期按用户选择的分阶段间隔执行。初始参数为本项目的冷启动先验；目前没有经过 408 学习者样本验证的预训练参数。

## 今日队列

1. 以当前错题本标记为复习范围，保留原始导入快照。
2. 没有复习模型的旧错题，列为待建档并加入今日队列。Excel 没有提供复习日期，不能还原过去的到期时间。
3. 已建档题只有到达可复习时间后才加入队列。今天晚些时候到期的题显示为“今天稍后”。页面每 30 秒及切回前台时刷新一次时间。
4. 先筛选到期题，再随机排列。同一轮保持顺序；新到期题追加到队列，已有题不因记笔记或刷新而重新洗牌。
5. “全部错题”允许查阅和额外练习。答对一次会更新日程，题目仍保留在错题本中；手动移出时暂停调度，已有记录保留。
6. 标答被勘误明确标为“标答存疑”的题，保留在全部错题中待核对，暂停自动判分驱动的日程更新。目前的导入数据中有 1 道此类题。

日期按 Asia/Taipei 计算，存储时间为 ISO 时间戳。

## 记忆模型

采用 HLR 的核心形式：

```text
p(recall) = 2 ^ (-elapsedDays / h)
h = 2 ^ (weights · features)
features = [1, sqrt(right + priorRight),
            sqrt(wrong + unknown + 0.5 * uncertain + priorWrong)]
```

`right`、`wrong`、`unknown`、`uncertain` 是当前模型接收的有效观察次数，分别记录独立答对、答错、明确选择不会、答对但不确定。短间隔重答和提前练习仍保留作答记录，但不增加这些有效观察次数。

原表正确/错误快照及启用调度前的本机作答只作为一次性弱先验。原表“不会”标记不当作一次负面记忆试验，也不生成复习日期、连续正确次数或训练样本。新模型从当前首次有效复习开始计时。

初始权重为 `[1, 1.7, -1.2]`。在至少间隔 12 小时的有效观察中，用回忆结果的平方损失梯度在线调整本题权重，学习率为 `0.2 / sqrt(1 + trained)`，并向冷启动权重施加弱正则约束。正向与负向特征权重有界，避免少量数据造成数值失控。

未把单道题的二元结果换算成一条虚构的实测半衰期；未直接移用 Duolingo 的词汇训练参数。

## 调度与更新

|本次情况|状态与安排|
|---|---|
|首次独立答对，或完成重学|进入巩固，首次约 3 天后复习；从作答时刻起保留完整 72 小时|
|后续到期独立答对|在到期且满足真实曝光间隔后逐步延长：7、14、30、60、120、240、365 天|
|答错|进入学习或重学，清零连续独立答对次数，约 10 分钟后再测|
|明确选择不会|单独记录不会，进入短期重学；不伪装为已选择某个错误答案|
|答对但不确定或用过提示|单独记录不确定，约 1 天后再测；不算作一次独立记住|
|短间隔改对或提前练习|不延长原有长期计划，不提高半衰期；保留最短冷却时间后再测|
|手动移出错题本|停止进入今日队列，保留模型与历史|

排期策略标识为 `spaced-3-7-14-30-v1`，随新作答的审计元数据记录。独立答对采用 3 → 7 → 14 → 30 → 60 → 120 → 240 → 365 天的间隔，均为从本次有效作答时刻计算的完整天数，365 天封顶。答错、不会仍为约 10 分钟重学；不确定/提示辅助答对为约 24 小时，不能提前改对后跳过这个等待。重学后有效独立答对从 3 天重新开始。

HLR 权重、真实时间间隔与遗忘估计继续更新，但不再用 `.85` 目标回忆率公式把排期压回次日。已有学习文件和旧排期不会在载入时批量重写；从下一次有效作答接入新排期。提前或短间隔重答保留计划，正确不自动移出错题本，争议标答不参与排期。

模型计时参考最近一次有日期的实际练习曝光。提前练习虽不增加长期稳定性，仍会影响最早可再次测量的冷却时间，以避免把刚看过答案后的答对计为长期记忆证据。

## 持久化、审计与撤销

- 每题的 `review` 保存阶段、权重、有效观察数、连续正确数、遗忘次数、最近有效复习时间和计划时间。
- 本机每次 `attempt` 保存真实时间、选择、对错、自评，以及此次是否参与调度、前后计划摘要和最早可再次复习时间。
- 原始工作簿与导入历史保持不变，未将导入快照变成本机新复习。
- 在本次结果页可撤销该次作答与日程。撤销会保留随后补写的笔记、草稿和独立的手动错题本操作。
- 正式应用记录保存于 Go 原生本机学习文件；重启后恢复，浏览器实现只作为兼容参考与跨语言测试，未启用跨设备同步或上传训练。

## 算法选择依据与边界

- HLR 提供公开的半衰期回归模型和实现，适合当前仅在本机记录逐题作答的应用。
- SM-20 官方通过 SuperMemo API 提供。本项目没有接入该外部服务。
- LECTOR 包含 LLM 语义相似度/干扰与个性化建模。本项目尚未构建或验证这样的语义数据，未将章节标签冒充语义相似度，也未声称复现 LECTOR。
- 自动判分是间隔调度的观察信号；模型不区分计算失误、概念误解和记忆遗忘的心理原因。它提供复习安排估计，不能据此断言学习者已经掌握或忘记某知识点。
