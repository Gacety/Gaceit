# 原生笔迹控制器

`Editor.strokes` 和正在采样的 `current` 是笔迹来源。纹理、分块、预览和空间索引都只是可丢弃的缓存；它们不拥有、删除或简化原始采样。会话文档、差量历史和宿主保存逻辑保持原有接口。

## 底图交接

`surface_pipeline.go` 管理统一的准备和交接流程：

- `surfaceState` 集中存放可丢弃的渲染状态，与笔迹、历史、相机输入分开。
- `surfaceFrame` 统一计算物理像素尺寸、相机和世界可见范围。
- `prepareSurface` 只准备画面，不往宿主画面叠加像素。普通显示、透明擦除、套索预览分别决定怎样显示，避免把旧墨迹先画到透明擦除结果下面。
- `surfaceView` 描述已经完整的画面及其相机、目标区域和笔画数量；分帧重建的半成品不能成为这个底图。
- `publishDry` 统一交接完整视野。`adoptSurface` 把最近的完整平移视野裁为当前操作的底图，避免后续落笔、缩放和套索退回旧相机。
- `ResetSurfaceCaches` 在一个边界丢弃所有渲染缓存，原始笔迹和历史不受影响。没有有效底图时，仍从矢量完整恢复。

局部撤销/重做收集编辑前后笔迹边界，像素擦除提交使用擦除路径的边界，通过 `repairDry` 按原始顺序修补；不再因为这些局部编辑无条件失效整个视口。没有有效底图或相机变化时仍保留完整恢复路径。分块同步复用未修改笔迹的边界与预处理几何；仅像素相位变化只清理栅格块，不重建世界空间索引。

## 导航和资源边界

平移继续使用 overscan、空间索引和当前帧的分块补边。平移后落笔复用最近完整视野，只追加新笔画。下一次平移若会继续串联旧视野，则从完整区域分块建立底图，截断跨操作的缓存依赖。使用中的 dry front 才是有效底图，备用槽可以为 nil。

缩放继续用最后完整视野作短时预览，180ms 后按每帧最多 8 条可见笔画 / 4096 工作单位重建。原有 256 条 / 1024 工作单位预览预算、原子笔画合成、输入打断和重排 generation 仍保留。缩放半成品还绑定文档 revision，旧任务不能提交为新文档的底图。

分块仍为 256px 内部 / 2px gutter、最多 124 块 / 32MiB RGBA 估算。分块记录物理像素的子像素相位，避免带分数相机原点的底图与补边不对齐。局部修补链最多 8 次，随后从矢量重建该小块，防止重复修补无限保留历史纹理。预算均不是应用总 GPU/RSS 上限。

MyGo 的固定 Metal 补丁只在后端确认纹理版本、尺寸均有效时停止递归旧依赖；纹理丢失、变更或尺寸不符时仍遍历依赖。普通软件渲染路径不变。空闲保留仍只选择最后完整视野，仍有 128MiB 后端预算和矢量恢复回退，没有定时保活。

## 套索与手势

屏幕预览和提交使用同一个按 z-order 合成器。缓存的选中图层只代表原先可见的部分；拖动后新露出的部分通过空间索引在当前帧补画，不把裁剪后的图片当成全部源笔迹。

丢弃套索的渲染资源不会丢弃已经收到的松手提交。窗口尺寸、主题和空闲恢复变化后，移动仍提交一次并可撤销。主题变化也更新活动笔画和手势取消快照的中性颜色，避免取消操作恢复上一主题的不可见笔迹。

## 验证

```sh
go test ./... -count=1
./scripts/test-canvas-metal.sh
./scripts/test-mygo-idle.sh
./scripts/build-desktop.sh
```

`surface_transitions_test.go` 对照完整矢量重绘，覆盖平移后套索、屏幕外笔迹移入、松手与视图变化交错、缩放被平移打断、重复平移后落笔、主题变化、撤销/重做及缓存重置。真实 Metal 测试另检查透明图层、空闲纹理和完整底图跳过过期依赖。QA 注入只在临时 Go overlay 中，不进入应用。

计时结果和限制见 `native-review/PERFORMANCE.md`。亚像素平移的位图插值不等同于重新栅格化后的抗锯齿；精确像素对比使用相同栅格相位。极长单笔仍为原子绘制，不能承诺所有输入都满足固定帧耗时。

## 增量路径与诊断（2026-11-14）

相邻块预生成与可见块分开：前者有分批预算且不发布半成品，后者仍立即修补。相机帧复用未变化的源索引；编辑只更新发生变化的网格单元。实时铅笔的 RNG/间距状态由 `ink.PencilStream` 保留，提交继续消费尚未显示的样本。局部实时缓冲扩展时迁移已有前缀，透明底图 checkpoint 只复制占用矩形。原始向量始终是恢复依据。

`InputDiagnostics().Render` 可显式导出 CPU 阶段耗时（最近 32 个样本）及缓存计数；不等同于 GPU 或硬件输入延迟。复制区域、冷块、完整恢复等限制及重现命令见 `native-review/PERFORMANCE.md`。
